# quanttide-tech（Go）

量潮技术工具箱——跨业务、跨领域流程整合。

## 安装

```bash
go get github.com/quanttide/quanttide-tech-toolkit/packages/go
```

```go
import quanttide "github.com/quanttide/quanttide-tech-toolkit/packages/go/pkg"
```

> 注意：本包标签带完整子路径前缀 `packages/go/vX.Y.Z`（Go 子目录模块要求）。

go test ./...
